# Abweichungen und offene Punkte

Stand: 30.09.2026 (Figma-Änderungen 29./30.09. eingearbeitet, 2-tarabao Commit 3ec19c7). Diese Liste sammelt alles, was bewusst vom Figma-Bestand
oder von `apps/medusa-storefront` abweicht, und Stellen, an denen Figma selbst
uneindeutig ist. Jede Zeile nennt die Quelle.

Bilder und Illustrationen übernimmt dieses Projekt aus Figma nicht. Jede Bildfläche
(Produktfotos, Teaser, Illustrationen wie ImpactScale oder Values) ist eine Platzhalterfläche
in `surface-placeholder` (`Visuals / Product / Image`). So bleiben Maße und Seitenverhältnisse
wie in Figma, und echte Bilder kommen später über `ImageModel.src` aus Medusa oder dem CMS.

## Offene Punkte zur Barrierefreiheit (axe-core 4, WCAG 2.1 AA, 29.09.2026)

Die Bibliothek läuft ohne ARIA- und Strukturfehler durch axe-core. Übrig bleiben Kontraste, die aus den
Figma-Tokens kommen. Das Projekt übernimmt die Tokens unverändert; die Designerin entscheidet über neue Werte.

| Token / Stelle                                          | Kontrast                                                                             | Ziel                                                                                                                                                                                                                      |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `error-content` #ff0000 auf surface warm / snow         | 3,8 : 1 / 4,0 : 1                                                                    | 4,5 : 1                                                                                                                                                                                                                   |
| `error-content` auf `error-bg` (InlineFeedbackElement)  | 3,2–3,4 : 1                                                                          | 4,5 : 1                                                                                                                                                                                                                   |
| `error-content` im Eingabefeld (Validierung, input-bg)  | 3,2 : 1                                                                              | 4,5 : 1                                                                                                                                                                                                                   |
| `success-content` #00cb6a auf `success-bg`              | 1,9–2,0 : 1                                                                          | 4,5 : 1                                                                                                                                                                                                                   |
| Cards / VoucherCard · special-theme lilac (Code, 40 px) | 1,6 : 1                                                                              | 3 : 1                                                                                                                                                                                                                     |
| RadioButtonGroup · State=Inactive (op-30)               | 1,9 : 1 — inaktive Bedienelemente sind von 1.4.3 ausgenommen                         | —                                                                                                                                                                                                                         |
| Components / Nutmixer · Trennlinie                      | Kontur 0,75 px im Primitive `cole-tint-60` (kein semantisches Token)                 | Primitive wie in Figma (`border-(color:--cole-tint-60)`), wie bei CategoryCard                                                                                                                                            |
| Templates / Section · Content Slots                     | Slots mit Fill, Mittelachse und min-h 3                                              | Kein Element je Slot (2.7); der Wrapper zentriert (items-center); min-h nur in Figma                                                                                                                                      |
| Templates / Page · Header                               | Header sticky                                                                        | `PageTemplate` setzt `sticky top-0 z-50`; `Header` allein bleibt im Fluss (Bibliothek)                                                                                                                                    |
| Templates / Page · Breadcrumb (8947:37169)              | Scroll-Verhalten nur als Annotation, da Figma-Prototypen keine Scrollrichtung kennen | `PageBreadcrumb`: sticky unter dem Header (`--header-height`), Variante `scroll-down:` (CSS `scroll-state` ab Chrome 144, sonst Skript), Demo in Storybook „Verhalten/Breadcrumb beim Scrollen“; `PageTemplate` nutzt sie |
